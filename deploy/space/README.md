# Recursa — development preview

Inspect the current progress of a recursive application-synthesis research workbench.

This public demo is **CPU-only and replay-only**. It serves three verified, host-assisted application showcases and recorded local-model trials across Task Management, Operations Analytics, and Aviation Operations. The deterministic CPU captures are labeled separately. [Benchmark protocol and measured results](https://github.com/jacobhroutzong/recursa/blob/main/docs/baseline-protocol.md)

Open **Build progress** to see the ordered 1–21 implementation record, the current phase and measured test evidence. The view checks for updates every 15 seconds and changes after a new release is published. It does not stream private engineering sessions.
