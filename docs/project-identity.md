# 1. Project identity

Recursa — Recursive Application Synthesis is an AI systems engineering and recursive-inference research project owned by Jacob Routzong. It tests whether programmatic inspection of external application specifications improves coverage and functional correctness relative to direct and structured nonrecursive model generation.

The portfolio destination is https://jacobroutzong.dev/projects/recursa/. This is a planned URL, not a deployed page. GitHub owner is `jacobhroutzong`; Hugging Face owner is `jacobroutzong`. Neither a dedicated remote repository nor a Space has been created.

Deliverables are the genuine RLM engine, working local application, recorded execution explorer, two verified generated examples, fair benchmark comparisons, reproducible research artifacts, public CPU replay demonstration and portfolio case study. These deliverables remain acceptance criteria, not claims of completion.

Recruiter narrative: inspect how a system works beyond a model's immediate context window. Engineering narrative: requirements, recursive inference, dependency contracts, bounded verification and provenance. Research narrative: measure when recursion helps or hurts under comparable budgets.

The master specification is preserved in `docs/specifications/master-01-20.md`. Progress and evidence are tracked in `docs/implementation-progress.md`.
